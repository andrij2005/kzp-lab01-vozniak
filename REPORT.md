3. Опис реалізації та рефакторингу
3.1. Клас-сутність Book.java
Переведено представлення даних із текстових рядків на об'єктну модель:
Інкапсуляція та незмінність стану: Поля title, author, pages, price оголошено як private final. Модифікація стану об'єкта після створення неможлива.
Перевірка інваріантів у конструкторі: Реалізовано перевірку вхідних даних. Створення об'єкта з порожньою назвою чи автором, від'ємною або нульовою кількістю сторінок (pages <= 0), від'ємною ціною (price < 0), а також значеннями Double.NaN чи Double.POSITIVE_INFINITY заборонено — викидається IllegalArgumentException з деталізованим повідомленням.
Статичний фабричний метод fromCsv(String csvLine): Автоматизує розбір CSV-рядка із розділювачем ;, обрізає пробіли (trim()), перевіряє кількість полів (очікується 4) та конвертує типи даних перед викликом конструктора.
3.2. Record BookSummary.java
Для збереження та передачі підсумкових статистичних показників використано конструкцію Java — record:
package ua.lpnu.kzp;

/**
 * Record для збереження підсумкових статистичних показників каталогу.
 */
public record BookSummary(
    int validCount,
    double avgPages,
    double maxPrice,
    double totalPrice
) {}

Використання record забезпечує незмінність результатів розрахунку та автоматичну генерацію аксесорів (validCount(), avgPages(), maxPrice(), totalPrice()), а також методів equals(), hashCode() і toString().
3.3. Інтеграція в Main.java
Читання CSV-рядків переведено на формування списку об'єктів List<Book>.
Рядки із некоректними даними перехоплюються через catch (Exception e) і фіксуються в списку помилок errors із зазначенням номера рядка та тексту виключення.
Обчислення статистичних показників виконується шляхом ітерації по списку Book, після чого результати агрегуються в об'єкт BookSummary.
Формат та структура вихідного звіту out/report.txt збережені відповідно до вимог предметної області.
3.4. Модульне тестування (BookTest.java)
Створено набір модульних тестів JUnit 5 для перевірки об'єктної моделі:
testValidBookCreation() — перевірка створення об'єкта та коректної роботи геттерів.
testConstructorInvariantsValidation() — перевірка виклику IllegalArgumentException при некоректних вхідних даних (порожня назва/автор, pages <= 0, від'ємна ціна, Double.NaN).
testFromCsvValidLine() та testFromCsvInvalidLine() — перевірка фабричного методу для коректних рядків та обробки помилок (невірна кількість полів, помилки формату чисел).
testBookSummaryRecord() — перевірка збереження та зчитування даних з BookSummary.
